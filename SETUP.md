# Spadewick setup guide

Spadewick 2.0 is an Electron desktop app for **Windows 10 and 11**. It is fully offline: it needs no account and makes no
network calls. This guide gets a copy of the source running, tested and packaged.

## 1. Requirements

| Needed | Version | Notes |
|--------|---------|-------|
| Windows | 10 or 11 | macOS and Linux are not supported in 2.0 |
| [Node.js](https://nodejs.org) | 20 or newer (22 LTS recommended; 24 works) | npm comes with it |
| git | any recent | |
| Internet | once, during `npm install` | downloads Electron and ready-made builds of the native module |

No C++ compiler or Visual Studio is needed: `better-sqlite3` is fetched as a prebuilt binary for both Node and Electron.

Only for the full test suite (not for running the app): [poppler](https://poppler.freedesktop.org/) (`pdftoppm` on your PATH,
for example `choco install poppler`) and `unzip` (Git for Windows includes it in `C:\Program Files\Git\usr\bin`).

## 2. Get the code and install

```
git clone https://github.com/Flashlighter-hub/spadewick.git
cd spadewick
npm install
```

`npm install` runs `scripts/native.mjs`, which fetches the Electron binary and both builds of better-sqlite3. If it fails, see
*Troubleshooting* below.

## 3. Run the app

```
npm run dev
```

The app opens with live reload. In development its settings, logs and default `projects/` folder live in
`%APPDATA%\spadewick`, not in the checkout; delete that folder to start fresh.

Try it: create a project, add a set, import or type some cards, pick a template (or use *New Set from Template…*), then
open the Export tab.

## 4. Run the tests

```
npm test            # unit + integration (fast)
npm run test:e2e    # end-to-end, drives the real window in Chromium (see tests/README.md)
npm run test:all    # both
```

A handful of tests depend on the machine (poppler missing, Chromium not downloaded, files locked by antivirus) and may
fail on a fresh checkout; `tests/README.md` explains the e2e setup. If you do not have the project's Chromium, point the
e2e tests at Edge:

```
set CHROMIUM_PATH=C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe
```

Two canvas zoom/pasteboard e2e tests are known to behave differently in Edge.

## 5. Build the Windows exe

```
npm run dist
```

This builds the bundles, packages them with electron-builder, and checks that the packaged app can load its database
module. The portable exe is written to `dist/` (for example `dist/Spadewick-2.0.0-dev.N-portable.exe`). Always use
`npm run dist`, not `electron-builder` on its own. The build is **unsigned**, so Windows SmartScreen shows a warning on first run.

## 6. Command line

After `npm run build`, run commands without a window:

```
node out/main/cli.js info
node out/main/cli.js export --help
```

Commands: `info`, `list`, `validate`, `preflight`, `export`, `render`, `compare`, `import`, `snapshot`, `profiles`, `watch`.
See [docs/command-line.md](docs/command-line.md).

## 7. Repository map

| Path | What is there |
|------|---------------|
| `src/main/` | main process: database, rendering, text engine, exports, the `core/` services, the CLI (`src/cli/`) |
| `src/renderer/` | the Svelte user interface |
| `src/shared/` | strings and constants shared by both |
| `resources/fonts/` | bundled open-licence fonts, each with its licence (see `THIRD-PARTY-NOTICES.md`) |
| `resources/profiles/` | the CGATS21 CRPC1 CMYK profile (licence file beside it) |
| `tests/` | unit, integration and end-to-end tests, and fixtures |
| `scripts/` | native-module fetch, packaging check, docs and font tools |
| `spikes/` | early technical experiments with their reports (generated output is not in the repository) |
| `PRD.md` | the product specification |
| `UPDATES.md` | change log of everything asked for after the PRD, with status |

## 8. Not in the repository, and why

- `node_modules/`, `out/`, `dist/`: generated by the steps above.
- Your projects and settings: they are stored outside the checkout (`%APPDATA%\spadewick`), or wherever you choose.
- ECI colour profiles (ISOcoated) and their PDF, used only in the CMYK experiment: their redistribution terms have not been
  confirmed. The app itself ships only the CGATS21 CRPC1 profile, whose licence allows redistribution.

## Troubleshooting

- **`npm install` tried to compile (node-gyp, MSBuild) and failed.** Delete `node_modules`, make sure Node is 20 to 24
  (install Node 22 LTS if yours is newer), and run `npm install` again.
- **`Error: Electron uninstall` on `npm run dev`.** Run `npm run native`, or `node node_modules/electron/install.js`.
- **`NODE_MODULE_VERSION` error on start.** Run `npm run native` (it rebuilds the right binary for Electron and Node).
- **Proxy or no internet during install.** The downloads come from GitHub releases; set `HTTPS_PROXY`.
- **A button does nothing.** View → Toggle Developer Tools, then send the red messages from the Console.
- **`npm audit` shows about 10 findings.** They are in development tools (Vite dev server, esbuild, the Svelte 4
  compiler) and are known; the shipped parts are current.
